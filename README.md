# Psych 1.0 to Legacy Chart Converter

https://melodiekit.github.io/psych2legacy.converter/

Exactly as it says, converts Psych Engine 1.0 charts to Legacy FNF charts (Pre-1.0 Psych, Kade, etc...)

However, it's not just that, this converter also has 2 extra options which are:
- Only Convert Sustains
- Convert as Event

Only Convert Sustains allows you to, well only convert sustains.
When you enable this, you will see the Sustain Type option letting you choose between the "Legacy" type or "New" type.
- "Legacy" is the default option. It converts Psych 1.0 chart sustains to Legacy chart sustains.
- "New" is used to convert Legacy chart sustains to Psych 1.0 chart sustains. This is needed because Psych Engine itself does not fix the sustains when it converts the chart to the 1.0 format.

Convert as Event will convert the events.json file to the 1.0 format.
This doesn't have to be checked if you're inputting a file that is named "events.json" as the code checks for it automatically.
